 git init создаёт пкстой репозиторий в текущей папке.
 git clone <ссылка> скачивет чужой репозиторий к себе на компьтер.
 git status показывает что происходит.
 git add <файл> добавляет файл в очередь на сохранение.
 git commit сохраняет добавленные изменения с подписью.
 git push отправляет свои сохранённые клммиты на удалённый сервер.
 git pull забирает чужие изменения с сервера к себе.
 git branch смотрит список всех веток репозитории.
 git checkout <ветка> переключается на другую ветку.
 git merge <ветка> влить изменениия из одной ветки в текущию.
